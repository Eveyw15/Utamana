# Utamana 视觉改版设计（2026-11-21）

## 意图

现在的前端（米色卡片、粉色强调色）功能完整但“太简陋”。用户希望整体变美，参考了 motionsites.ai（Golden Portal、Coastal Cards、VHS Archive）、reactbits.dev 等站点的动态感。核心想法：**一首歌一个主题背景，播放时背景会动**；音乐主题，用**黑胶唱片**的视觉语言。风格要**简洁**，不要花哨装饰。

确认过的原型（浏览器里看过、用户认可）保存在 `.superpowers/brainstorm/527-1795237786/content/`：
- `apple-music-v2.html`（练习页横竖屏布局）
- `full-app.html`（三页统一风格、歌词只在进入时亮一次、加宽边距；其中曲库已被下面替换）
- `library-rows.html`（曲库最终方案）

## 目标

1. 全应用统一为深色、Apple Music 风格：背景是当前歌曲封面（或用户上传的背景图）模糊后的颜色缓慢流动。
2. 练习页改成 Apple Music 布局：宽屏左封面右歌词，手机竖屏。
3. 曲库改成“一行一组”的黑胶唱片行，行顺序用户可调。
4. 去掉独立的编辑页：顶栏只剩「曲库 / 练习」。编辑变成练习页的“编辑模式”；新建歌曲走三步引导。
5. 设置页换成同一套视觉（毛玻璃分区卡片）。
6. 每首歌可上传一张背景图，替代封面生成背景。

## 非目标

- 背景视频（以后再说；本次只做图片）。
- 改动任何功能逻辑：播放、变速变调、节拍器、打点、对齐、循环、队列、同步、翻译、注音等行为一律不变。
- 首页 hero、扇形卡片轮播（看过，用户不要）。
- 联网搜索带时间戳的歌词（LRCLIB / 网易云）、从音频自动生成节拍器：已和用户商定作为**下一个项目**。本次的新建引导要给它们留好位置（第 1 步、第 3 步），但不实现。

## 反目标（做成这样就算失败）

- 歌词一闪一闪：歌词**不能**跟每一拍跳动。
- 衬线字体。全部无衬线，保持现有 `--ui-font` / `--lyric-font`（用户在设置里选的歌词字体照旧生效）。
- 装饰过多：不要光点粒子、暗角、玻璃描边高光、高亮色块。用户明确说过“好丑，我喜欢简洁”。
- 歌词贴边：歌词离边框要有足够留白。
- 长条“书脊”卡片、抽出后看不到歌名：都被否决了。歌名必须一直可见。

## 设计

### 0. 交互原则：能选就不让输入（用户要求）

凡是能给出候选的地方，都让用户点选；键盘输入只作为最后的兜底（一个不显眼的“＋ 自定义”或“手动输入”）。具体落到：

- **歌名 + 歌手 + 封面一次选完**：新建引导第 2 步直接列出联网搜索结果（iTunes 结果本身带歌名、歌手、专辑封面），点一条就同时填好三项。搜索词自动预填：导入文件的文件名，或歌词第一行；用户只在结果都不对时才改搜索词或手动填。编辑模式里点封面浮层的“联网搜索”同理，选中一条时询问是否同时更新歌名和歌手。
- **歌手**：手动填时，下拉给出曲库里已有的歌手供选择。
- **标签、歌单**：显示曲库里已有的全部标签 / 歌单为可点的胶囊，点一下加入或移除；“＋ 新建”才需要输入。
- **学习状态**：分段按钮（想学 / 在学 / 已学会 / 不设置），不用下拉框。
- **节拍器分段**：拍号用胶囊选择（2/4、3/4、4/4、6/8 等）；BPM 用点按测速或 ±1 / ±0.1 微调按钮，数字仍可点开手动改；分段起点用“设为当前播放位置”按钮，而不是手打时间。
- **速度、Key**：滑条旁边加常用档位胶囊（速度 50% / 75% / 90% / 100%，Key −2 / 0 / +2 一类），滑条保留做细调。
- **翻译**：主要入口是“自动翻译”和“导入文件”，文本框保留用于小修改。
- **歌词**：本次仍是粘贴 / 导入（下一个项目加搜索后，搜索结果同样是点选）。

原有的数字输入、文本框等不删除，只是降为次要入口。

### 1. 背景（全局）

- 来源：`song.bg`（用户上传）优先，否则 `song.cover`，都没有时用这首歌的**默认主题**（见下）。不属于某首歌的页面（新建引导第 1 步等）用“雾蓝”主题。
- **默认主题**（用户要求，清新的马卡龙 / 莫兰迪色系，参考 `default-themes-v2.html`；`default-themes.html` 的深色版已被否决）：10 套——马卡龙：樱花、薄荷、柠檬、薰衣草、天空；莫兰迪：雾粉、灰绿、雾蓝、燕麦、藕紫。每套给出生成封面用的 3 色（底色、圆、墨色）和背景流动用的 4 色，色值以原型文件为准。
  - 没有封面的歌显示**生成封面**：浅色平涂底 + 右上一个实心圆 + 左下一条细圆弧 + 左下角墨色大号歌名首字 + 左上小字 “UTAMANA”。不用模糊色块。曲库唱片、练习页左栏大封面、黑胶中心标签都用它。
  - 主题背景的遮罩比封面背景轻一些（约 rgba(0,0,0,.22)），保留粉彩感，同时白字仍可读（实现时检查对比度，必要时加深）。
  - 新歌按歌曲 ID 的哈希自动分到一个主题；用户可在编辑模式的封面浮层里点选别的主题。选择存到新字段 `song.theme`（主题名），随云同步；不设时按哈希。
  - 有封面时主题不生效。
- 形态：2–3 个封面图层，`blur(~70px) saturate(~1.7)`，各自以不同速度缓慢旋转（26–44s 一圈），上面盖一层黑色半透明保证文字对比。参考 `apple-music-v2.html` 的 `.bg`。
- 曲库、设置页、新建引导：背景压得更暗（约 rgba(0,0,0,.5)），**不跟拍**。曲库里鼠标指向哪张唱片，背景换成那首歌**封面**的颜色（过渡要柔和）；曲库悬停只用封面、不读上传的背景图，避免把大图放进曲库索引（我的决定）。
- 练习页：
  - 播放时图层旋转，暂停时静止（`animation-play-state`）。
  - 每一拍背景整体轻微变亮一次（brightness 约 1.12 → 1，约 0.5s 衰减），拍点来自已有的 `song.beat` 节拍分段（`src/beat.ts` 的 Section）。没有节拍数据时不闪。拍相位由当前播放时间计算（已有 40ms 轮询的 `time`）。
- `prefers-reduced-motion: reduce` 时背景不动、不闪（我的决定）。
- 打印 / PDF 不受影响，照旧白底黑字（现有 `@media print` 规则必须继续生效）。

### 2. 主题色与组件

- 全应用改为深色：文字白、次要文字 ~62% 白、分隔线 ~16% 白、粉色强调色保留（`#f07c96` 一类）用于振假名、进度等少量地方。
- 主要按钮：白底深字的胶囊；次要按钮：10% 白的半透明胶囊。
- 分区卡片（编辑模式的分页内容、新建引导、设置页、练习设置面板、弹出的音量/人声滑条、歌单队列列表）：`rgba(255,255,255,.1)` + `backdrop-filter: blur(~24px)` + 细描边，圆角约 16px。参考 `full-app.html` 的 `.box`。
- 顶栏：透明，导航是半透明胶囊，当前项白底。
- 现有浅色/深色 `prefers-color-scheme` 两套变量不再需要两套；统一为深色（我的决定）。

### 3. 练习页

保留现有结构和所有控件，只改布局与外观。参考 `apple-music-v2.html` + `full-app.html`（练习视图）。

- **宽屏（≥ ~900px，具体断点留给实现）**：左栏约 34% 宽：大封面（圆角、阴影）、歌名、歌手、播放条（进度、播放/暂停、时间、音量、循环、人声、歌单队列 ☰、练习设置入口）。右栏：歌词，左对齐，可滚动，上下渐隐（现有 mask 做法）。左右外边距约 6%。
- **手机竖屏**：顶部一行小封面（~56px）+ 歌名/歌手；中间歌词占满；播放条固定底部。左右边距约 24px。
- **歌词样式**：日文大号加粗（约 28px 宽屏 / 22px 手机，仍乘以用户设置的歌词大小比例），振假名、罗马音、翻译保留。当前句纯白；其他句约 35% 白并轻微模糊（~1.2px）。**当前句只在变成当前句的那一刻做一次轻微放大/发光（约 0.6s），之后不再动。** 下一句、循环范围等现有状态需要有可辨识但低调的样式（具体留给实现）。
- 歌词居中滚动行为、手动滚动暂停自动滚动、点击跳句、编辑单句等交互不变。
- **练习设置面板**：不再常驻右侧（会挡歌词），改为点按钮弹出的毛玻璃浮层（我的决定）。面板内容不变：速度、Key、节拍器（含点按测速、分段设置）、显示开关、重新打点、自动校准打点、打印。浮层是**非模态**的：点外面不关闭（只用 × 或再点入口按钮关），打开时歌词仍可滚动、点击，空格打点照常工作；浮层位置不能挡住当前句（宽屏放在左栏上方或右下角，手机放在底部抽屉，具体留给实现）。分段设置展开时浮层可以变宽。
- 歌名标题（现在在歌词上方的 `.sheet-title`）在宽屏移到左栏，在手机移到顶部小封面旁；打印时仍需出现在纸面上。

### 4. 曲库

参考 `library-rows.html`。

- 顶部：大标题“曲库”+ 歌曲数，右侧“调整顺序”和“＋ 新歌曲”。
- **一行一组**，每行横向滑动。默认顺序：在学、最近播放、收藏、想学、已学会、全部。
  - 在学 / 想学 / 已学会：按 `status` 过滤。
  - 收藏：`fav`。
  - 最近播放：按“最近打开时间”倒序，最多 ~12 首。
  - 全部：所有歌曲（保证没状态、没收藏、很久没开的歌也找得到）。
  - 行内排序：最近打开优先。
  - 空行不显示（我的决定）。
- 一首歌可出现在多行。
- **唱片卡**：正方形唱片套（封面；无封面时用默认主题的生成封面），下方始终显示歌名、歌手、右侧小字（学习状态；在“最近播放”行显示“5 分钟前”这类相对时间）。
  - 悬停：唱片套微抬微转，黑胶从套子右侧滑出约 1/3 并旋转，黑胶中心标签是封面。背景换成这首歌的颜色。
  - 点击：打开这首歌并进入练习页（不新增详情页——详情页看过但最终方案未包含，我的决定）。注意现在点卡片后停在哪个标签页要确认一下；新行为统一进练习页。
  - **收藏按钮**（用户要求）：封面右上角，圆角矩形（约 34×30px、圆角 10px）、深灰半透明底 + 背景模糊，里面是白色描边的镂空星；已收藏时星变实心白。一直显示（不靠悬停），点它不会打开歌曲。不再用金色 ★。
  - 其他快捷操作：切换学习状态、`⋯` 菜单（编辑、加入歌单、**删除这首歌**）。宽屏悬停时出现在封面左下角；触屏（`(hover: none)`）上一直显示在卡片下方，点它们不会打开歌曲（我的决定）。参考 `library-rows.html`。
  - **删除歌曲只在这里**（用户要求）：`⋯` → 删除这首歌，弹确认（“歌词和音频都会删掉，不能恢复”），行为与现有删除一致（本地删除 + 云端墓碑）。删的是当前打开的歌时，当前歌切到新建空白歌（延续现有行为）。
- **调整顺序**：点“调整顺序”，所有行折叠成一条条，可拖动或用 ↑↓ 调整；“完成”退出。顺序存本机（localStorage），不同步（我的决定）。
- **歌单和标签**：现有歌单、标签筛选和“▶ 按歌单练习”必须保留。做法（我的决定）：在行上方保留一排筛选胶囊（歌单、标签）；选中某个时，行视图替换为该歌单/标签的单个唱片网格，歌单时显示“按歌单练习”按钮；再点取消回到行视图。
- 手机：行照样横滑，卡片缩小到约 2.3 张一屏；悬停效果改为无（触屏没有悬停）。

### 5. 最近打开时间

- 新字段：每首歌的“最近打开时间”（打开即更新，也就是现在 `openSaved` 被调用的时候）。
- 只存本机，不同步到云端（我的决定，避免每次打开都触发同步）。存在本机索引（`SongMeta`）里还是单独的 key，留给实现；不能导致打开歌曲时 `updated` 改变（否则会触发云同步和“最近修改”语义变化）。

### 6. 导航与编辑模式

- 顶栏导航只有「曲库 / 练习」。原「编辑」标签页去掉。
- 编辑入口只有两个：练习页里的「✎ 编辑」按钮（宽屏在左栏歌名旁，手机在顶部歌名旁），以及新建歌曲（见第 7 节）。
- **编辑模式 = 练习页原地切换**，布局与背景不变：
  - **左栏**：
    - 点封面弹出小浮层：联网搜索封面、上传封面、移除封面；没有封面时可点选默认主题；上传背景图、移除背景图；显示当前背景来源（“用封面自动生成”/“默认主题”/“已上传”）。
    - 歌名、歌手原位变成输入框。
    - 下面一排：学习状态、收藏、标签（现有 ChipsInput）、歌单（ChipsInput）。
  - **右栏**：原歌词区域换成分页「歌词 | 翻译 | 音频」（参考 `edit-mode.html`）：
    - 歌词：现有文本框及导入 .txt/.lrc、导出 .lrc、读音写法提示；文本框左侧显示每句已有的时间（只读）。
    - 翻译：自动翻译（Google）、导入、文本框，外加“移除翻译”按钮（用户要求，自动翻译不满意时一键清空 `trans`；带确认）。
    - 音频：原曲 / 伴奏 / 人声三轨的上传、文件名、保存到本地、移除；开发环境下的链接导入保留。
  - 右上角「完成」回到练习视图。改动照旧自动保存；现有“保存”按钮和“已保存 hh:mm”提示保留在编辑模式顶部。
  - 编辑模式**不显示播放条**（用户要求）。切到「编辑」时自动暂停；在练习页里改节拍器、改读音、改单句不会打断播放（用户要求，2026-11-21 修订）。离开练习页（回曲库、设置、个人主页、新建）时自动暂停。
- **背景图**：上传的图片缩放到长边约 1920px、JPEG 质量约 0.8，存为 data URL 到新字段 `song.bg`；`bg` 进入云同步（`src/cloud.ts` 的 Data、push、pull 三处）。不放进 `SongMeta`。
- 打印 / PDF 仍从练习设置面板触发，打印内容与现在一致。

### 7. 新建歌曲引导

曲库「＋ 新歌曲」进入一个全屏三步引导（同样的深色背景，中性渐变），顶部显示步骤 1/2/3，可返回上一步：

1. **歌词**（必填）：大文本框粘贴歌词，或导入 .txt/.lrc。（下一个项目会在这里加“按歌名搜索歌词”。）
2. **选歌**：自动用文件名或歌词第一行搜索，列出候选（封面 + 歌名 + 歌手），点一条即填好歌名、歌手、封面。都不对时可改搜索词，或点“手动填写”出现两个输入框（歌手带曲库已有歌手的候选）。
3. **音频**（可跳过）：三轨上传。（下一个项目会在这里加“自动生成节拍器”。）

完成后保存并进入练习页。中途离开（点曲库）时，已填了歌词就保存为新歌，否则丢弃（我的决定）。

### 8. 设置页

设置页没有导航按钮了，入口保持顶栏右侧的「设置」按钮。

设置页用同一套分区卡片外观，内容不变。

## 约束

- 技术栈不变：React 19 + Vite + 纯 CSS（`src/index.css`），不加 UI 库或动画库。
- 不改功能行为；现有单元测试（`node --test src/*.test.ts`）必须继续通过。
- 字体：无衬线，沿用 `--ui-font` / `--lyric-font`。
- 封面目前存为 300px 的 data URL；练习页宽屏的大封面会被放大，可能略糊。可以接受；若要更清晰，留作以后（不在本次）。
- 性能：背景动画只用 transform/filter/opacity，大模糊层数控制在 3 层以内；页面不可见时可暂停。
